# 💰 Personal Expense Tracker

A simple Python-based Personal Expense Tracker that helps users manage daily expenses efficiently. This project was developed as part of my Python Development Internship.

## 📌 Features

- Add New Expense
- View All Expenses
- Search Expenses by Category
- Calculate Total Expense Summary
- Monthly Expense Summary
- Delete Expense
- SQLite Database Storage
- Input Validation
- Rich CLI Tables

## 🛠️ Technologies Used

- Python
- SQLite
- Rich Library

## 📂 Project Structure

```
Personal-Expense-Tracker/
│
├── data/

```

## ▶️ How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the project

```bash
python main.py
```
